# Darth Vader introduction page

A plain, early-2000s-style Star Wars fan page built as static HTML and CSS.

## Deploy to Cloudflare Pages

Connect this GitHub repository to Cloudflare Pages. No build command or environment variables are needed. Set the output directory to the repository root (`.`).

The costume photo is by [Sam Howzit](https://commons.wikimedia.org/wiki/File:SWC_6_-_Darth_Vader_Costume_(7865106344).jpg), licensed under [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). It is cropped to fit the page layout.
